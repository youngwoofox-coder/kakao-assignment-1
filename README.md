## 과제 목표
이번 과제를 통해 무엇을 배우고자 했는지 간단하게 작성해요.

- 라이브러리 없이 Vanilla JS만으로 상태(State)를 관리하는 흐름을 익히고 싶었어요.
- LocalStorage를 활용해 새로고침 후에도 데이터가 유지되는 영속성 처리를 직접 구현해 보고 싶었어요.
- 날짜 기반 UI(주간·월 네비게이션)를 JavaScript Date 객체만으로 다루는 방법을 익히고 싶었어요.

## AI 활용 내역
AI를 활용해 구현하거나 수정한 내용을 기록해요.

### Todo CRUD 구현하기
- AI 활용 내용 :
기본 CRUD 뼈대 코드를 AI에게 요청해 HTML 레이아웃과 추가·수정·삭제·완료 토글 함수를 받았어요. 각 Todo 항목에 수정·완료·삭제 버튼이 달린 DOM 구조와 유효성 검증 메시지까지 포함된 초안을 받았어요.
- 직접 수정한 부분 : 수정 모드 진입 시 기존 버튼(완료·수정·삭제)을 숨기고 저장 버튼만 노출하는 UX를 `startEdit` 함수에서 직접 조정했어요. 또한 수정 입력창에서도 Enter 키로 저장할 수 있도록 `keydown` 이벤트를 추가했어요.
- 수정 이유 : AI가 생성한 코드는 수정 중에도 다른 버튼이 그대로 노출돼 의도치 않은 클릭이 발생할 수 있었어요. 수정 상태임을 명확히 구분하는 게 사용성에 더 좋다고 판단했어요.

### 날짜별 Todo 관리 (주간 네비게이션)
- AI 활용 내용 :
주간 뷰에서 월요일~일요일 날짜 배열을 만드는 `getWeekDates` 함수 로직과 날짜 셀 DOM 생성 코드를 AI에게 요청했어요.
- 직접 수정한 부분 : 날짜 셀에 해당 날짜의 Todo 개수를 뱃지로 표시하는 `getTodoCountByDateKey` 연동 부분과, 날짜 선택 시 `selectedDate`를 갱신해 월 표시·주간 뷰·Todo 목록 세 영역이 함께 동기화되는 `render()` 호출 구조를 직접 설계했어요.
- 수정 이유 : 날짜 셀만 교체하는 부분 갱신으로는 세 영역 간 상태 불일치가 생길 수 있어서, 단일 `render()` 함수로 항상 동기화되도록 구조를 통일했어요.

### 월 네비게이션 (월말 날짜 보정)
- AI 활용 내용 :
이전·다음 달 이동 시 날짜 오버플로 문제(예: 1월 31일 → 2월 이동 시 3월 3일로 밀림)를 방지하는 방법을 물어봤어요.
- 직접 수정한 부분 : AI가 제안한 단순 `setMonth` 방식 대신, 날짜를 1일로 고정한 뒤 월을 변경하고 이동한 달의 마지막 날로 클램핑하는 로직으로 직접 재작성했어요.
- 수정 이유 : 단순 `setMonth` 호출은 JS Date의 자동 오버플로 동작 때문에 예상치 못한 날짜로 이동하는 버그가 있어서, 명시적으로 날짜를 보정하는 방식이 더 안전하다고 판단했어요.

## 구현하면서 고민한 점

- 고민한 점 : 다른 Todo 앱과 어떤 차별점을 둘지 가장 오래 고민했어요. 기능을 늘리는 것보다 "실제로 쓰고 싶은 앱"이 되는 게 중요하다고 생각했고, 그 기준으로 무엇을 넣고 무엇을 빼야 할지 판단하기 어려웠어요.
- 해결 방법 : 사용자 관점에서 "오늘 할 일만 보고 싶다", "이번 주에 할 일이 얼마나 있는지 한눈에 보고 싶다"는 흐름을 먼저 그려보고, 그 흐름에 꼭 필요한 기능만 붙이는 방식으로 범위를 좁혔어요. 기능보다 사용 흐름을 먼저 정하니 무엇을 만들어야 할지 자연스럽게 정해졌어요.

## 과제 회고
과제를 마치고 느낀 점, 아쉬운 점, 다음에 개선하고 싶은 점을 자유롭게 작성해요.

- 잘한 점 : 기능 목록보다 사용자 흐름을 먼저 고민한 덕분에, 군더더기 없이 깔끔한 구조로 마무리할 수 있었어요. 복잡하게 만들고 싶은 유혹을 참고 필요한 것만 남긴 점이 스스로 만족스러워요.
- 아쉬운 점 : AI가 처음부터 완성도 높은 코드를 만들어줘서, 직접 고민하고 수정할 여지가 생각보다 적었어요. 결과물은 좋았지만 "왜 이렇게 짰는가"를 내 힘으로 고민하는 경험이 부족했던 것 같아요.
- 다음에 시도해볼 것 : 처음부터 AI 없이 혼자 설계하고 구현해본 뒤, AI 코드와 비교해보는 방식으로 진행해보고 싶어요. 내가 놓친 부분과 AI가 잘한 부분을 직접 비교해야 더 많이 배울 수 있을 것 같아요.
